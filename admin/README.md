# お知らせ管理画面セットアップ

この管理画面は、指定したGoogleアカウントだけがスマホから登録・削除できるGoogle Apps Scriptです。

## 1. Apps Scriptプロジェクトを作成

1. 対象スプレッドシートを開く
2. メニューの「拡張機能」→「Apps Script」
3. `Code.gs` の内容をエディターへ貼り付け
4. `Index.html` を追加
5. ファイル名を `Index` にする（拡張子は `.html` のまま）

## 2. 登録担当者を設定

Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」から、次を追加します。

- プロパティ名：`ADMIN_EMAILS`
- 値：登録担当者のGoogleメールアドレス
- 複数人の場合はカンマ区切り

任意でPDF保存先フォルダーを設定します。

- プロパティ名：`DRIVE_FOLDER_ID`
- 値：GoogleドライブのフォルダーID

未設定の場合はGoogleドライブのマイドライブ直下へ保存します。

## 3. スプレッドシートを設定

スクリプト内の設定を確認します。

- `SPREADSHEET_ID`：`1ALstLpWWSMPcdOjt6Egh5Msxcoo_bshHvB4uInvlqyk`
- `SHEET_NAME`：`新着情報`

シートの先頭行は自動で「日付、カテゴリ、内容、リンク」となるようになっています。

## 4. ウェブアプリとして公開

1. Apps Script右上の「デプロイ」→「新しいデプロイ」
2. 種類：「ウェブアプリ」
3. 実行ユーザー：「自分」
4. アクセス：「Google アカウントを持つ全員」または組織内ユーザー
5. デプロイ後のURLを登録担当者へ共有

許可されたメールアドレス以外は登録・削除できません。

## 5. ホームページへの反映

スプレッドシートを「ウェブに公開」し、CSV形式の公開URLを取得して `index.html` の `csvUrl` に設定します。

スマホから管理画面へアクセスし、日付、カテゴリ、タイトル、PDFまたは既存リンクを登録すると、新着情報へ反映されます。
